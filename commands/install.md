---
description: Install the Ctrl+G shell binding into your bash or zsh rc file
allowed-tools: Bash
---

Run `bash "${CLAUDE_PLUGIN_ROOT}/install.sh"` and report its output. If the user's shell is not bash or zsh, or they name one, pass `--shell bash|zsh`. Then tell them to run `source` on the rc file named in the output, or open a new terminal.
