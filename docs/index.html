Install

Clone it, run the installer, and pick your key and short aliases. Works with the Claude Code CLI you already have.

$ git clone https://github.com/alparslanpolat/hey-shell ~/hey-shell
$ ~/hey-shell/install.sh
$ source ~/.zshrc

Then try hse how to free up disk space for the command with an explanation, or hsc "<command>" to check one before you run it.

Generated commands are only placed on your prompt, never executed. Always read them before pressing Enter.
